# MacKit

macOS 日常维护工具箱 —— 把零碎的维护操作收拢到一个本地网页界面上，点点鼠标就能用。

完全离线、零依赖：后端只用 Node 内置模块，前端是原生 HTML/CSS/JS，不需要 `npm install`，不装任何第三方包。

服务只监听 `127.0.0.1`，局域网内其他设备访问不到。

## 能做什么

| 模块 | 用途 |
| --- | --- |
| **总览** | 一键体检：Homebrew / Git / Rime / 代理等环境状态一览 |
| **Homebrew 管家** | 列出可升级的软件包并逐项选择「代理 / 直连」升级；搜索并安装 Formula（命令行工具 / 库）与 Cask 应用；卸载 formula / cask / tap；本机没装 Homebrew 时可一键安装 |
| **系统初始化** | 把代理别名写进 shell 配置、设置 Git 全局项、把 GitHub Token 存进 macOS 钥匙串、配置代理端口 |
| **Rime 输入法** | 安装 / 更新 rime-ice 词库，切换皮肤与布局，启用万象语法模型，写入配置 |
| **应用解隔离** | 批量去掉 App 上的 quarantine 属性（解决"打不开 / 已损坏"） |
| **备份中心** | 把上述配置备份到你的 WebDAV 服务器（NAS），换机器时一键恢复 |

## 环境要求

- **macOS**（Apple Silicon / Intel 都可以）
- **Node.js 20 或更高** —— 终端里执行 `node -v` 看一眼。没有的话：
  - 已装 Homebrew：`brew install node`
  - 没装：到 <https://nodejs.org> 下载安装包

不需要联网（除了下载软件本身），也不需要安装任何依赖。

## 快速开始

### 1. 拿到代码

```bash
git clone https://github.com/Giaosm/MacKit.git
```

或者点页面右上角 **Code → Download ZIP** 再解压。

### 2. 双击启动

进入 `app` 文件夹，双击 **`MacKit.command`**。

会弹出一个终端窗口，等一两秒，浏览器会自动打开界面。

### 3. 开始使用

左侧边栏切换各个模块。所有涉及系统改动的操作，界面都会先弹确认框，并显示即将执行的命令。

## 如果提示"无法验证开发者"

用 Download ZIP 的方式下载时（`git clone` 不会有这个问题），macOS 会给文件打上隔离标记，双击时提示无法打开。两种解决办法：

- **右键点 `MacKit.command` → 选「打开」**，在弹窗里再点一次「打开」。只需操作一次，之后就能正常双击。
- 或者改用 `git clone` 获取代码。

## 怎么关闭

界面**右上角**有一个「关闭服务」按钮。点它，后台服务就停了，页面会提示"服务已关闭"，这时可以放心关掉标签页。

**直接关掉浏览器标签页也可以** —— 后台服务会继续运行。这样做的好处是：正在进行的升级、下载任务不会被中途打断。想再回到界面，重新双击 `MacKit.command` 即可，之前的数据和进度都还在。

如果要彻底停掉后台服务，重新打开界面点一下「关闭服务」。

## 数据放在哪

运行数据都在 `~/.mackit/` 下：

| 路径 | 内容 |
| --- | --- |
| `config.json` | 你的设置（权限 600） |
| `runtime.json` | 当前服务的端口与进程号 |
| `logs/` | 各次任务的执行日志（保留最近 50 个任务 / 30 天） |
| `history/` | 任务历史（保留最近 10 次） |
| `cache/` | Homebrew 环境快照、Cask 搜索索引（24 小时过期） |
| `server.out` | 服务启动日志 |

**卸载**：删掉 MacKit 目录，再执行 `rm -rf ~/.mackit` 即可。写入 shell 配置的别名、以及存进钥匙串的凭据，需要你自己按需清理。

## 说明

- 端口默认 `18080`。若被占用会自动往后顺延，实际端口显示在启动日志里。
- 部分操作需要授权：安装 Homebrew 会要求管理员密码（通过系统弹窗输入，密码不落盘、不写日志）；修改 `~/Library/Rime` 下的配置、去除系统 App 的隔离属性也可能需要管理员权限。
- 涉及删除或覆盖的操作（卸载软件包、覆盖别名、覆盖配置等）一律有二次确认。
